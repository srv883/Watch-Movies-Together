# Watch-Movies-Together
A free P2P chrome extension to watch any tv shows, or movies together in any streaming platform

**Download the latest version:** [wt-latest.zip](https://github.com/srv883/Watch-Movies-Together/raw/main/wt-latest.zip)
(unzip → `chrome://extensions` → Developer mode → remove the old Watch Together → Load unpacked → pick the unzipped folder; both of you need the same version).

From v1.31 the extension's popup tells you when a newer version is out (it reads `latest.json` from this repo).
